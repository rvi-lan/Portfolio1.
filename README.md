# Ravi Lan A. Ravena — Student Portfolio

A responsive single-page student portfolio with a warm editorial design and a profile photo in the Home section.

## Files
- `index.html` — portfolio content and sections
- `style.css` — layout, colors, typography, and responsive styling
- `script.js` — mobile navigation and current year
- `images/ravi-profile.jpg` — profile photo used in the Home section

## View locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Extract this ZIP.
2. Open your GitHub repository and upload the files and `images` folder (not just the ZIP).
3. Make sure `index.html` is in the repository root, alongside `style.css` and `script.js`.
4. Open **Settings → Pages**.
5. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and open the website URL shown in Settings → Pages.

Update the sample project descriptions and email address in `index.html` before publishing if you want to use your real project/contact details.
